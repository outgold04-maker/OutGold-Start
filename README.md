## iPhone (iOS) — desenvolvimento

A versão para iOS exige um aplicativo nativo diferente do APK. O projeto inicial está em [ios/OutGoldStart_iOS26_SOURCE.zip](ios/OutGoldStart_iOS26_SOURCE.zip), com a interface original e um bridge experimental para **AlarmKit do iOS 26+**. Este arquivo é **código-fonte**, não um arquivo de instalação iOS, e ainda não foi compilado, assinado, testado no iPhone ou publicado na App Store.

Para distribuir aos usuários, precisamos compilar com Xcode, usar assinatura Apple Developer, testar os alarmes no aparelho e fazer publicação via TestFlight ou App Store. A versão de iPhone **não está disponível para instalação pública** enquanto essas etapas não estiverem concluídas.
