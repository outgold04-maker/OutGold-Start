# OutGold Start 5D — Android

Versão oficial aprovada: **v5.1.6** (nome do aplicativo: **OutGold Start**).

## Distribuição pública

Após o primeiro envio do arquivo `OutGold_Start_v5.1.6.apk` para **esta pasta** (`downloads/`), a automação GitHub Actions [publicar-outgold-start.yml](../.github/workflows/publicar-outgold-start.yml) verifica a integridade e o SHA-256 do APK aprovado, e publica automaticamente a versão no GitHub Releases.

**Link público de download, válido somente após a publicação:**

https://github.com/outgold04-maker/OutGold-Start/releases/latest/download/OutGold_Start_v5.1.6.apk

## Como enviar o APK

1. Baixe o APK aprovado com o nome exato `OutGold_Start_v5.1.6.apk`.
2. Nesta pasta, use **Add file → Upload files** para enviar o APK.
3. Confirme **Commit changes**. A automação publica o link direto assim que concluir.

Não coloque na pasta uma versão de teste ou um APK recompilado. A publicação verifica o hash exato:

`8681ed8e2aff9d2f3d103de8daa37d49aeacda14cc8823ce4b19c6494adb2bec`
