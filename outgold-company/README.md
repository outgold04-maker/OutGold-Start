# OutGold Company — Painel Mobile (v1)

Base experimental e independente para organizar projetos, tarefas, status e progresso diretamente no navegador Android / Acode.

## Como abrir no Acode

1. Abra o repositório pelo GitHub no celular e escolha **Code → Download ZIP**.
2. Extraia o ZIP numa pasta permitida ao Acode.
3. Abra o arquivo `outgold-company/index.html` no Acode.
4. Use **Pré-visualização** ou abra em um navegador para testar.

## Recursos que funcionam

- Criar, editar, filtrar e excluir projetos;
- Criar, concluir, filtrar e excluir tarefas;
- Progresso calculado a partir das tarefas;
- Salvar automaticamente em `localStorage` no navegador;
- Exportar/importar backup JSON;
- Layout adaptável a celular e computador.

## Limitações importantes

- Dados ficam somente no navegador/dispositivo, não no GitHub nem em um servidor.
- Sem login, banco de dados ou notificações nativas.
- Este painel **não substitui** o sistema OutGold Company que está sendo desenvolvido no computador, nem representa os 199 itens do planejador anterior.
- O logotipo OutGold original não está embutido nesta versão; nenhuma imitação foi criada.
- O repositório ainda se chama **OutGold-Start**; o nome exibido da aplicação é **OutGold Company**. Para renomear o repositório, acesse suas configurações no GitHub.

## Segurança

Não insira senhas, tokens ou dados de clientes neste protótipo local. Os backups JSON são arquivos de texto simples.
