# OutGold — Websites oficiais

Este diretório publica apenas os sites **institucionais públicos**.

- `outgold-sites/company`: site oficial da OutGold Company.
- `outgold-sites/tecnologia`: site comercial OutGold Tecnologia.
- O arquivo `logo-original.jpg` é o logotipo real da OutGold, recuperado do material já aprovado, **não redesenhado**.
- Portfólio verificado: MON PETIT DREAM (Cliente VIP). Somente link para o catálogo público.
- **NÃO** publicar painéis internos, credenciais, bancos, arquivos de clientes ou interfaces de Gestão aqui.
- Sites estáticos não substituem a futura central privada OutGold Company, que deverá usar repositório privado, autenticação forte e backend próprio.
- Repositório compartilhado com protótipo anterior apenas como solução operacional inicial; migrar para repositório próprio quando possível.

Render: publicar cada pasta em um **Static Site** distinto com `publishPath` correspondente e `buildCommand` `echo 'OutGold site estático'`.
